# МебельОрг — информационная система магазина мебели

Учебный проект, созданный для отработки навыков проектирования баз данных и разработки веб-приложений.

Компания занимается продажей мебели. Работникам и пользователям важно получать актуальную информацию об остатках товаров на складах, поэтому реализовано следующее:

## Возможности

- **Авторизация** по логину и паролю из БД + вход в роли гостя.
- **Роли**: 
  - гость и клиент видят каталог без фильтрации/сортировки/поиска;
  - менеджер может фильтровать, сортировать и искать товары, просматривать заказы;
  - администратор управляет товарами (добавление, редактирование, удаление).
- **Каталог товаров** — фото, наименование, категория, описание, производитель, поставщик, цена, единица измерения, количество, скидка.
- **Поиск** по всем текстовым полям, 
- **Сортировка** по цене и количеству, 
- **Фильтр** по диапазонам скидок.

## Стек

- **Python 3.12+**
- **Streamlit** — веб-интерфейс
- **SQLite** — база данных
